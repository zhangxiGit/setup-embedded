# setup-embedded — Claude Code Embedded Dev Skill

[中文文档](README_CN.md) | [English Docs](README_EN.md)

A Claude Code skill for embedded firmware development: **Build → Flash → Log Capture** loop.

Requires [rcw-tool](https://gitee.com/zhangxi95/zxx-log) for log capture features.

## Quick Install

```bash
cp -r setup-embedded ~/.claude/skills/setup-embedded
```

Then in Claude Code: `/setup-embedded`
