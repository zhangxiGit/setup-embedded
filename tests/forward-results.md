~~~~text
```powershell

此时必须确认：

- `AppProject = app\app.uvprojx`
- 精确的 `AppTarget`

```powershell

  throw "UV4 build failed: exit $buildExit"

  throw 'Build log does not contain 0 Error(s)'
}
if (-not (Test-Path -LiteralPath $appArtifact)) {
  throw "AppArtifact not found: $appArtifact"
}

  throw 'AppArtifact was not regenerated by this build'

```

3. 烧录前运行强制 image guard，并完整显示 JSON：

```powershell
$guardOutput = & powershell -NoProfile -ExecutionPolicy Bypass `
  -File scripts\verify-firmware-image.ps1 `
  -ImagePath $appArtifact `
  -Mode app `
  -BootStart '<BootStart>' `
  -BootEndExclusive '<BootEndExclusive>' `
  -AppStart '<AppStart>' `
  -AppEndExclusive '<AppEndExclusive>' `
  -AppStartEraseBoundaryConfirmed 2>&1

$guardExit = $LASTEXITCODE
$guardText = $guardOutput -join [Environment]::NewLine
$guardText

if ($guardExit -ne 0) {
  throw "Image guard failed: exit $guardExit"
}

$guardJson = $guardText | ConvertFrom-Json
if ($guardJson.safe -ne $true) {
  throw 'Image guard did not return safe: true'
}
```

只有 exit code 为 `0` 且 JSON 中 `safe: true`，才继续。

4. guard 通过后创建无 `erase` 的 J-Link command file，并烧录同一个 `AppArtifact`：

```powershell
$jlink      = '<JLinkPath>'
$device     = '<Device>'
$interface  = '<Interface>'
$speedKHz   = '<SpeedKHz>'
$commandFile = [IO.Path]::GetFullPath(
  (Join-Path $workspace '.embedded\jlink-app-flash.jlink')
)

$workspacePrefix = $workspace.TrimEnd('\') + '\'
if (-not $commandFile.StartsWith(
  $workspacePrefix,
  [StringComparison]::OrdinalIgnoreCase
)) {
  throw 'J-Link command file is outside workspace'
}

try {
  @(
    "device $device"
    "si $interface"
    "speed $speedKHz"
    "loadfile `"$appArtifact`""
    'r'
    'g'
    'q'
  ) | Set-Content -LiteralPath $commandFile -Encoding ASCII

  $jlinkOutput = & $jlink -NoGui 1 -ExitOnError 1 `
    -CommandFile $commandFile 2>&1
  $jlinkExit = $LASTEXITCODE
  $jlinkText = $jlinkOutput -join [Environment]::NewLine
  $jlinkText

  if ($jlinkExit -ne 0 -or $jlinkText -match '\bSkipped\b|ERROR') {
    throw "J-Link flash failed: exit $jlinkExit"
  }

  # 仅在输出能证明实际 download/program/verify 成功时报告烧录成功。
} finally {
  if (Test-Path -LiteralPath $commandFile) {
    Remove-Item -LiteralPath $commandFile -Force
  }
}
```

最终分别报告 build 和 flash 结果。本次不执行 UART/debug，因此不能宣称硬件行为已验证。
~~~~
